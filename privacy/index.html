Privacy Policy

How Home Grocery and the Home Grocery Encrypted Backup Adapter collect, process, encrypt, and protect your data.

Effective Date: November 17, 2026 • Canonical: https://homegrocery.online/privacy

1 Application Purpose & Scope

Home Grocery (घरगुती किराणा यादी) is an offline-first household grocery planning, budgeting, and monthly expense management application developed for families. It provides digital grocery checklists, estimated cost calculators, Devanagari localization (मराठी), and A4 printable receipts.

The Home Grocery Backup Adapter is an administrative disaster recovery subsystem designed solely to create encrypted, offsite database archives of household grocery records to safeguard against hardware failure, data loss, or server decommissioning.

मराठी सारांश: होम ग्रोसरी हे कुटुंबासाठी किराणा नियोजन व बजेट व्यवस्थापन ॲप्लिकेशन आहे. डेटा नष्ट होऊ नये म्हणून हे ॲप खाजगी व कूटबद्ध (encrypted) बॅकअप सुविधा पुरवते.

2 Google OAuth Authentication & Limited Scope

When the administrator enables cloud backup synchronization, the application connects to Google APIs using standard OAuth 2.0 Desktop Loopback Flow (RFC 8252).

Requested Scope: https://www.googleapis.com/auth/drive.file
Classification: Non-Sensitive / Per-File Permission
Access Level: Strictly restricted to files and folders created directly by the Home Grocery application.

What the application CANNOT do:

  • The application CANNOT access, view, list, read, or modify your personal files, Google Docs, Sheets, photos, or existing folders in Google Drive.
  • The application CANNOT access files created by other apps or services.
  • The application CANNOT read your personal emails, calendar, contacts, or device identity.
  • The application CANNOT share or publish your Google Drive data to any third party.

What the application CAN do:

  • Create a single designated private folder named HomeGrocery_Backups in your own personal Google Drive.
  • Upload client-side encrypted backup archives and cryptographic verification manifests to this dedicated folder.
  • Download previously created backup archives for disaster recovery verification and restoration drills.
  • Prune older backup generations under a strict two-generation retention policy to conserve your personal Drive storage quota.
गुगल ड्राइव्ह परवानगी: ॲप केवळ स्वतः तयार केलेल्या बॅकअप फाइल्सपुरतीच मर्यादा ठेवते (drive.file). तुमच्या वैयक्तिक गुगल फाइल्स किंवा फोटोंना ॲप कधीही हात लावत नाही.

3 Client-Side Cryptographic Protection

Home Grocery operates under a Zero-Knowledge Cloud Architecture. All database records are packaged and encrypted locally before any network transmission takes place.

  • PostgreSQL Native Extraction: Logical backups are generated using PostgreSQL binary custom format (pg_dump -Fc).
  • Authenticated Encryption: Archives are encrypted using AES-256-GCM (Galois/Counter Mode), providing both confidentiality and cryptographic tamper-detection.
  • Key Derivation: Cryptographic keys are derived using PBKDF2 with 100,000 rounds of SHA-512 and cryptographically secure 16-byte random salts.
  • Unique Initialization Vectors: Every backup file generates a fresh 12-byte random IV.
  • No Plaintext Transmissions: Plaintext SQL dumps are never uploaded to Google Drive or any remote server.
  • No Keys in Manifest: Cryptographic manifest files (.json) store only file sizes and SHA-256 hashes for verification; they never contain encryption passwords, tokens, or credentials.

4 OAuth Credential & Token Protection

Security of authorization tokens and credentials is strictly enforced through local physical isolation:

  • No Cloud Token Storage: Google OAuth refresh tokens and Client Secrets are stored exclusively in local, restricted configuration files (.env.drive-backup and drive-token.json) on the administrator's local machine.
  • Git Exclusions: All token files, keys, and OAuth client JSONs are rigorously excluded from git tracking via .gitignore rules.
  • No Public Exposure: Tokens and secrets are never embedded in frontend code, public static assets, or browser bundles.
  • Revocation at Any Time: The user can immediately revoke the app's authorization at any time via Google Account Security → Third-party apps with account access.

5 Retention & Deletion Policy

To ensure reliable disaster recovery without consuming your Google Drive storage allowance, Home Grocery enforces a conservative Two-Generation Retention Policy:

  • The system retains the Latest Verified Backup and the Previous Verified Backup.
  • Older backups are pruned only after a newly uploaded archive has completed round-trip download and bit-for-bit SHA-256 decryption verification.
  • Because archives are compressed with zlib and encrypted with AES-256-GCM (~1.4 MB each), total storage consumption is typically less than 5 MB (<0.03% of Google Drive's 15 GB free allowance).

6 General User Data Handling

  • Zero Advertisements & Trackers: Home Grocery does not integrate third-party advertising SDKs, tracking pixels, or marketing brokers.
  • No Sale of Personal Data: We do not sell, rent, monetize, or trade any personal information, shopping lists, or household budget data.
  • PIN Security: User authentication PINs are hashed using salted scrypt cryptographic algorithms with memory-hard cost factors; plaintext PINs are never stored or logged.
  • Local Offline Persistence: In mobile and desktop client applications, grocery data is cached in local SQLite / IndexedDB storage to allow full offline usability.
